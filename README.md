## Как работает бот для пробива

Пользователь передаёт исходный идентификатор, выбирает направление поиска и получает отчёт с возможными совпадениями. Автоматизация экономит время, но не превращает результат в доказанный факт. Одинаковое имя, фотография или username могут принадлежать разным людям.

Обычно проверка строится так:

1. ввод исходных данных;
2. поиск совпадений в доступных источниках;
3. группировка результатов;
4. переход пользователя к первоисточникам;
5. ручное подтверждение важных связей.

## Какие данные можно проверять

| Запрос | Возможный результат | Главное ограничение |
|---|---|---|
| Номер телефона | Регион, формат, открытые объявления и упоминания | Номер мог сменить владельца |
| Username | Публичные аккаунты и страницы с таким никнеймом | Одинаковый ник не подтверждает личность |
| Имя и фамилия | Открытые профили, публикации и документы | Возможны однофамильцы |
| Электронная почта | Публичные упоминания и связанные страницы | Нельзя использовать для доступа к аккаунту |
| Фотография | Возможные совпадения изображения | Сходство лица требует ручной проверки |
| Автомобиль | Доступные сведения по номеру или другим данным | Результат нужно сверять с официальными источниками |

Наличие функции в конкретном боте не означает, что по каждому запросу будет найден подробный отчёт. Полнота зависит от цифрового следа и доступности источников.

## Как выбрать хороший бот для пробива

### Прозрачная официальная ссылка

У проекта должен быть сайт или канал, с которого выполняется переход на один конкретный username. Для рассматриваемого сервиса официальный сайт ведёт на [Запустить бота](https://sherlokk.bot/).

### Понятные ограничения

Надёжный сервис не гарантирует результат по любому человеку. Он предупреждает об однофамильцах, старых сведениях и необходимости проверки первоисточников.

### Отсутствие запроса кодов Telegram

Для OSINT-поиска не нужен пароль, код авторизации или резервный пароль двухэтапной аутентификации. Запрос таких данных — причина немедленно закрыть бот.

### Проверяемый результат

Полезный отчёт содержит ссылки, даты или названия источников. Чем проще открыть первоисточник, тем легче отделить реальное совпадение от ошибки.

### Понятные тарифы

До оплаты пользователь должен видеть число запросов, стоимость и ограничения. Не следует переводить деньги администраторам копий проекта.
